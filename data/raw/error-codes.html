Error Codes Reference

Authentication Errors (E1xxx)

E1001 — Invalid Credentials

Returned when the BIOME_API_KEY is missing, malformed, or revoked. HTTP status: 401.

Resolution: Set the BIOME_API_KEY environment variable and verify the token has not expired. Contact your administrator if the issue persists.

E1002 — Rate Limit Exceeded

The client has sent more than 100 requests per minute. HTTP status: 429.

Resolution: Implement exponential backoff. The Retry-After header specifies the number of seconds to wait before retrying.

E1003 — Token Expired

The BIOME_API_KEY has passed its expiry date (90 days). HTTP status: 401.

Resolution: Request a new token from your administrator.

Resource Errors (E2xxx)

E2001 — Resource Not Found

The requested document, chunk, or collection does not exist. HTTP status: 404.

Resolution: Verify the resource ID. Ensure the corpus has been indexed by running seed_index.py.

E2002 — Missing Deployment Target

A deployment was initiated without a BIOME_DEPLOY_TARGET environment variable. HTTP status: 400.

Resolution: Set BIOME_DEPLOY_TARGET to dev, staging, or production before deploying.

E2003 — Collection Already Exists

Attempted to create a ChromaDB collection that already exists with a different schema. HTTP status: 409.

Resolution: Delete data/index/chroma/ and re-run ingestion, or change EMBEDDING_COLLECTION_NAME in .env.

Ingestion Errors (E3xxx)

E3001 — Chunking Failed

Ingestion succeeded but chunking produced zero chunks from a document. HTTP status: 422.

Resolution: Ensure the document is not empty and uses a supported format (Markdown, TXT, HTML, PDF).

E3002 — Index Out of Sync

The BM25 index and ChromaDB vector store contain a different number of chunks. HTTP status: 500.

Resolution: Delete data/index/ and re-run seed_index.py to rebuild both indexes.

E3003 — Duplicate Document

The submitted document is a near-duplicate (cosine similarity above DEDUP_THRESHOLD) of an already-indexed chunk. The document is skipped. HTTP status: 200 (not an error, logged as a warning).

Resolution: No action required. If you intentionally want to re-index modified content, delete the existing index and re-run ingestion.

Generation Errors (E4xxx)

E4001 — LLM Timeout

The language model did not respond within OLLAMA_TIMEOUT seconds. HTTP status: 504.

Resolution: Increase OLLAMA_TIMEOUT in .env or switch to a faster model.

E4002 — Insufficient Context

Retrieval confidence is below INSUFFICIENT_CONFIDENCE_THRESHOLD. A structured "I don't know" response is returned rather than a hallucinated answer. HTTP status: 200.

Resolution: Rephrase the question or ensure the relevant documents are indexed.
